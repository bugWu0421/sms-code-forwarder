# 夜间流水线详解

> 把「拉快照 → 导出 → 挖掘 → 日报」串成一条可定时执行的流水线，
> 全程离线、免登录、免调试器。适用于"每天自动了解微信里的工作信号"。
> 快速上手见 [README](../README.md)，本文讲配置、定时接入与故障排查。

## 组成

| 脚本 | 作用 |
|---|---|
| `pull_nightly.sh` | 退出原版微信 → 启动重签副本 → 免密 sudo 克隆最新数据库 → 兜底用用户身份发布 → 恢复原版微信。输出 `PULL_OK` / `PULL_FAIL` |
| `export_all.py`（工具链提供） | 解密导出，见 [wechat-chatlog](https://github.com/tcsn-xy/wechat-chatlog) |
| `mine_v2.py` | 按身份分组挖掘：对方提问、待办线索、活跃会话、排除项统计 |
| `build_daily_brief.py` | 生成昨日简报：数据新鲜度、按身份消息量、待办线索、待归类群、信息源状态 |
| `send_push.py` | 可选：把文本推送到飞书（open_id / 凭证从环境变量或本机配置读取，脚本内不落任何密钥） |

## 配置：pipeline.local.json

所有本机相关信息（工具链位置、账号目录、输出目录、身份规则）都在仓库根的
`pipeline.local.json`，该文件**不进 Git**（`*.local.json` 已被 `.gitignore`
覆盖）。复制 [`pipeline.example.json`](../pipeline.example.json) 后按需修改：

| 字段 | 说明 |
|---|---|
| `chatlog_dir` | wechat-chatlog 工具链检出位置（导出、密钥、`.venv` 都在它下面） |
| `wx_account` | 微信账号目录名（`wxid_…`），留空则自动发现唯一账号 |
| `topic_dir` / `brief_dir` | 挖掘报告 / 日报输出目录 |
| `rules_file` | 记录归类规则与 open_id 的 markdown（供 send_push.py 与日报引用） |
| `recording_dir` | 可选：语音转写结果目录，日报会列出昨日新转写 |
| `lark_mcp_bin` | 可选：lark-mcp 可执行文件，用于日报检测飞书令牌状态 |
| `exclude_pat` | 会话名排除正则（空 = 不排除任何会话） |
| `identity_patterns` | `[["身份名", "会话名匹配正则"], …]` |
| `identity_order` | 报告小节顺序，留空则按 patterns 顺序 + 「私聊/其他」 |

配置文件路径可用环境变量 `PIPELINE_CONFIG` 覆盖（便于测试）；
`pull_nightly.sh` 也可用环境变量 `CHATLOG_DIR` 临时指定工具链位置。

## 定时执行

macOS `launchd` / `crontab` / 任务编排器均可，每天凌晨依次：

```bash
TOOL=~/tools/wechat-chatlog            # 与 chatlog_dir 一致
bash pull_nightly.sh                                        # ①
"$TOOL/.venv/bin/python" "$TOOL/scripts/export_all.py"      # ②
python3 mine_v2.py                                          # ③
python3 build_daily_brief.py                                # ④
```

`pull_nightly.sh` 需要免密 sudo 规则（`sudoers` 中允许工具链的
`clone_data.py` 以 `NOPASSWD` 运行）；没有 sudo 规则时改用工具链的
`clone_data_local.py`（微信退出状态下克隆）替代第 ① 步。

## 故障排查

| 现象 | 原因与处理 |
|---|---|
| `PULL_FAIL: 副本微信未能启动` | 副本被微信自动更新破坏，需回工具链重跑 `capture_keys.py --keep-copy` 重签；密钥一般无需重抓 |
| 日报提示"快照已 N 天未更新" | 夜间拉取连续失败，按上一行处理；期间流水线用最近一次快照继续 |
| 导出报"账号口令 0 条" | 抓密钥时未在监听窗口内登录/操作微信，加大 `--seconds` 重试 |
| 群被归错身份 | 改 `pipeline.local.json` 的 `identity_patterns` / `exclude_pat`，日报的"待归类"一节会给出候选 |

## 隐私边界

* 挖掘与日报只在本机读导出的 CSV，不发起任何网络请求；`send_push.py` 是
  唯一外发点，且只发送你主动喂给它的文本。
* 身份规则、账号、输出目录都在 `pipeline.local.json`，公开仓库不含任何
  本机会话名与个人信息。
* 工具链的 `export/`（聊天导出）、`data/`（快照）、`keys/`（密钥）是私密
  数据，不上传、不外发、不贴在线服务。

# 飞书接入手册（短信验证码转发 App）

> 本手册配套「短信验证码转发」App 使用。配置完成后，手机收到的验证码短信会在几秒内推送到你的飞书群里。
> 全程免费，不需要服务器、不需要注册飞书开放平台开发者账号。

---

## 一、建一个接收消息的群

1. 打开飞书，左侧消息列表顶部点「**+**」→「**发起群聊**」
2. 如果必须选人才能建群：随便拉一个家人/同事进来，**建好后把他移出群**（不影响机器人）
3. 群名建议改成「验证码接收」

之后所有验证码都会推到这个群，手机/电脑飞书实时可见，相当于你专属的"验证码收件箱"。

## 二、添加自定义机器人

1. 进群 → 点右上角「**…**」（群设置）→ 找到「**群机器人**」
   （找不到就在设置页顶部搜索框搜「群机器人」）
2. 点「**添加机器人**」→ 选择「**自定义机器人 Custom Bot**」
3. 填名字（如"短信转发"），进入安全设置

> ⚠️ 必须是**普通群聊**。"话题群 / 频道"不支持自定义机器人。

## 三、安全设置（关键一步，只勾「签名校验」）

| 选项 | 是否选择 | 原因 |
|---|---|---|
| 自定义关键词 | ❌ 不要选 | 验证码短信内容五花八门，配关键词必然漏发 |
| **签名校验（加签）** | ✅ **选这个** | 点一下生成密钥（`SECRET` 开头），最安全且不影响内容 |
| IP 白名单 | ❌ 不要选 | 手机网络 IP 不固定，选了会莫名收不到 |

勾选「签名校验」后，**复制生成的密钥**保存好，下一步要用。

## 四、拿到 Webhook 地址

完成创建后页面会显示 Webhook 地址，形如：

```
https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**务必确认机器人已出现在群的"机器人列表"里**——只在配置页复制了地址但没点底部「完成／添加」的话，机器人处于未启用状态，发消息会报错（见下方错误码表）。

## 五、填进 App

1. 打开「短信验证码转发」App：
   - 模式选「**飞书机器人**」
   - **URL 框**：粘贴 Webhook 地址
   - **密钥框**：粘贴签名密钥（没开启签名校验就留空）
2. 点「**发送测试**」→ 群里出现"这是一条测试消息，收到说明配置成功 ✅"即成功
3. 打开「**总开关**」→ 点「**保存设置**」（v1.1 起切出界面也会自动保存）。下方状态区「当前生效配置」里显示 总开关: 开 ✅ 才算生效

收到的消息格式：

```
📩 收到验证码短信
验证码: 123456
发件人: 1069012345678
内容: 【京东】您的验证码为123456，10分钟内有效…
时间: 2026-10-19 17:05:32
```

## 六、报错对照表

| App 显示 | 含义 | 解决办法 |
|---|---|---|
| `code:19007 Bot Not Enabled` | 机器人未启用 | 机器人没创建完成或已被停用：回群设置→群机器人，确认它在列表里；不在就重新添加并点完底部「完成」；在但停用就打开开关 |
| `code:19021 sign match fail` | 签名不匹配 | App 里的密钥和机器人配置页的密钥不一致：重新复制密钥，注意别带空格/换行 |
| `code:19022 Invalid timestamp` | 时间戳偏差 | 手机时间不准：开自动对时 |
| HTTP 请求失败/超时 | 网络不通 | 检查手机能否上网；URL 是否完整（结尾没被截断） |

## 七、限制与注意

- **限流**：每个机器人 100 条/分钟、5 条/秒，验证码场景不可能触顶
- **保密**：Webhook 地址 + 密钥泄露的后果是别人能往你群里发消息（**读不到**你的消息），但也别公开
- **不要共用**：⚠️ 每个人给自己的群配自己的机器人。**绝不要多人共用同一个 Webhook**——那等于把你的所有验证码发进别人的群
- 飞书机器人只能发群消息，不能私聊；群里只有你+机器人就等同于私聊

## 八、测试清单

1. App 点「发送测试」→ 群里收到 ✅
2. 用另一个手机给本机发：`【测试】您的验证码是123456，10分钟内有效` → 群里收到且提取出 `验证码: 123456` ✅
3. 发一条普通消息（如"吃饭了吗"）→ 开着「仅转发验证码」时不转发 ✅
4. 若第 2 步没收到：打开 App 看「最近一次转发结果」→ 无记录说明广播没进来（检查后台保活设置）；有记录说明网络/配置问题（对照错误码表）
